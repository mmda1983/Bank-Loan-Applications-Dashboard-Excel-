# 📊 Bank Loan Applications Dashboard (Excel)

## 🔍 Project Overview

This project presents an interactive **Banking Loan Applications Dashboard** built using **Microsoft Excel**. The dashboard provides a comprehensive view of loan performance, customer risk, and lending trends, enabling data-driven decision-making for financial institutions.

## 🎯 Objectives

* Analyze loan applications and funding performance
* Monitor good vs bad loan distribution
* Track key financial KPIs such as interest rates and debt-to-income ratio
* Identify trends by loan purpose, term, employment length, state, and time

## 📌 Key KPIs

* **Total Loan Applications:** 14.4K
* **Total Funded Amount:** $169.0M
* **Total Amount Received:** $183.5M
* **Average Interest Rate:** 12.30%
* **Average Debt-to-Income Ratio:** 13.35%

## 📈 Dashboard Insights

* **Loan Quality Analysis:** Good vs Bad loans with funded and received amounts
* **Term Analysis:** Distribution across 36-month and 60-month loans
* **Monthly Trends:** Total loan applications by month
* **Purpose Analysis:** Debt consolidation, credit cards, home improvement, and more
* **Employment Length:** Loan applications categorized by borrower experience
* **Geographical View:** Loan applications by U.S. state
* **Interest Rate Comparison:** Charged-off, current, and fully paid loans

## 🛠 Tools & Techniques

* Microsoft Excel
* Pivot Tables & Pivot Charts
* Slicers for interactive filtering
* Conditional Formatting
* Dashboard design & layout optimization
